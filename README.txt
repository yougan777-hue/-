HALO MOD (Fabric 1.20.1, тільки на клієнті)

Що робить: малює золотий німб над усіма гравцями, в тому числі невидимими.
Клавіша H вмикає/вимикає. Німб не видно крізь стіни.

ЯК ОТРИМАТИ .jar БЕЗ ВСТАНОВЛЕННЯ ПРОГРАМ
1. Зареєструйся на github.com (безкоштовно).
2. Створи новий репозиторій (кнопка New), назви як хочеш.
3. Натисни "uploading an existing file" і перетягни ВСЕ з розпакованої папки,
   разом з папками src та .github (папка .github прихована - увімкни показ прихованих файлів).
   Натисни Commit.
4. Відкрий вкладку Actions, дочекайся зеленої галочки (1-3 хв).
5. Зайди у виконаний запуск, внизу в Artifacts скачай halo-mod, розпакуй - там halo-mod-1.0.0.jar.

ЯК ВСТАНОВИТИ
1. Постав Fabric Loader для 1.20.1 (fabricmc.net) і Fabric API для 1.20.1 (Modrinth).
2. Поклади halo-mod-1.0.0.jar і fabric-api у папку mods.
3. Запусти профіль Fabric 1.20.1.
